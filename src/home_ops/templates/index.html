Metodología Transparente

1. Ingestión & Trazabilidad

Scraping estructurado de listings en Idealista, persistiendo metadatos completos y fechas de avistamiento para trazabilidad inmutable.

2. Tracking de Observaciones

De las {{ n_obs_total }} capturas, se aíslan {{ n_unique }} inmuebles únicos y {{ n_repeated }} observaciones repetidas en el tiempo (seguimiento de publicación activa, no duplicados difusos).

3. Modelo de Scoring 5D

Algoritmo multicriterio ponderado: diferencial vs. mediana zonal ({{ kpis.median }} €/m²), liquidez de zona, eficiencia de superficie, estado y tipología.

4. Gestión de Riesgo Preventivo

Se aplica penalización metodológica base (scam_risk_score = 10) a los {{ n_unique }} registros sin categorizarlos indebidamente como fraudes confirmados.

5. Auditoría HITL

Las {{ n_scored }} oportunidades con Score ≥ 70 se someten a validación documental humana (verificación registral y cargas) previo a su selección.

Límites del Sistema & Frescura de Datos
  • Fecha de Corte de Datos: {{ cutoff }} — los datos analizados corresponden exactamente al snapshot capturado el {{ cutoff }}. No se han incorporado eventos posteriores.
  • Insuficiencia de Serie Temporal (1 Semana): disponibilidad de una única semana de muestra ({{ week.date }} con {{ week.n }} observaciones). No es técnicamente admisible modelar tendencia o estacionalidad con este horizonte.
  • Precios de Oferta Publicados: los importes reflejan precios anunciados por vendedores en Idealista; las operaciones notariales reales suelen negociarse con descuentos adicionales.
  • Muestra Acotada ({{ n_unique }} Inmuebles Únicos): el análisis se circunscribe a los {{ n_unique }} registros verificados. Home-Ops es un ejercicio de ingeniería de datos y no constituye asesoramiento financiero.
  • Cero Datos Inventados o Sintéticos: no se publican versiones ficticias, runs inventados ni conteos de tests ficticios. Todos los números derivan estrictamente de la base de datos.
